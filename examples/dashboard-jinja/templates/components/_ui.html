{# Primitives, built from the specs in components//README.md. A Jinja macro is the closest this stack has to a component. It takes no props object and has no variants library -- which is the interesting part: if the system needs one to be usable, it is not really a token system. #} {%- macro lucide(name, size=None, cls='') -%} {#- `size` defaults to --control-icon, read from the generated Python tokens. control.icon is the string "16px", so strip the unit for the attribute. -#} {%- set px = (size or control.icon)|replace('px','') -%} {%- endmacro -%} {%- macro button(label, variant='outline', size='md', icon_name=None, extra='') -%} {%- endmacro -%} {%- macro icon_button(name, label, extra='') -%} {%- endmacro -%} {%- macro badge(label, tone='outline', icon_name=None) -%} {%- if icon_name %}{{ lucide(icon_name, size=control['icon-xs']) }}{% endif -%} {{ label }} {%- endmacro -%} {%- macro checkbox(checked, label, indeterminate=False) -%} {#- `border-strong`, not `border`: an unchecked box outlined in `border` is 1.26:1 against a light row and fails WCAG 1.4.11. -#} {%- endmacro -%} {%- macro avatar(initials) -%} {{ initials }} {%- endmacro -%}
